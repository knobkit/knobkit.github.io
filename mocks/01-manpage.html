knobkit

Your AI app, live as you type.

name

knobkit — declare widgets, write event handlers, done. The same file runs entirely in the browser — no server at all — or with handlers on a stateless Node server. Swap one line.

synopsis

import { knobkit, chat } from "knobkit";

const convo = chat({ placeholder: "Say something…" });
const app = knobkit({ title: "Echo bot", widgets: [convo] });

app.on(convo.sent, async ({ text }) => {
  convo.say({ role: "user", content: text });
  convo.say({ role: "assistant", content: [...text].reverse().join("") });
});

app.serve(); // or app.mount("#root") — same file, zero servers

description

browser-owns-state
A knobkit server keeps nothing. Handlers pull the attributes they read and send structured edits back. Restart, redeploy, scale — no one's app breaks.
one-file-two-tiers
Prototype fully client-side (WebGPU models included), move handlers to Node when you need secrets or big models — by changing the last line.
events-not-reruns
Plain on(event, fn) handlers. No full-script re-execution, no reactive graph, no widget-key gymnastics.
