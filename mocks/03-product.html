what is knobkit?
Declare widgets, write on(event, handler) functions — that's a complete app. No reruns, no reactive graph.
where does it run?
Entirely in the browser — or with handlers on a stateless Node server. Same file. The browser owns all state either way.

code

import { knobkit, chat } from "knobkit";

const convo = chat({ placeholder: "Say something…" });
const app = knobkit({ title: "Echo bot", widgets: [convo] });

app.on(convo.sent, async ({ text }) => {
  convo.say({ role: "user", content: text });
  convo.say({ role: "assistant", content: [...text].reverse().join("") });
});

app.serve(); // handlers on a stateless servermount("#root"); // no server at all
